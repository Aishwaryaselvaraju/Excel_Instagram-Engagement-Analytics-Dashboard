# Instagram Engagement Analytics Dashboard

## Project Overview

The **Instagram Engagement Analytics Dashboard** is an Excel-based data analytics project designed to analyze Instagram content performance and identify engagement patterns across different content categories.

The dashboard transforms raw Instagram analytics data into interactive visualizations and key performance indicators (KPIs), enabling users to quickly understand content performance and engagement trends.

## Objectives

- Analyze Instagram engagement and likes across content categories
- Identify high-performing content categories
- Track key engagement metrics using KPIs
- Compare performance across different categories
- Present insights through interactive charts and visualizations
- Convert raw social media data into actionable insights

## Tools & Technologies

- **Microsoft Excel**
- PivotTables
- PivotCharts
- Excel Formulas
- KPI Cards
- Data Cleaning
- Data Visualization

## Dashboard Features

- Total Likes KPI
- Average Likes KPI
- Category-wise Likes Analysis
- Engagement Performance Comparison
- Interactive PivotCharts
- Category-based performance analysis
- Summary dashboard for quick insights

## Key Insights

The dashboard helps identify:

- Which content categories generate higher engagement
- Differences in performance between content categories
- Overall engagement patterns
- Content areas that may require further analysis or optimization

## Skills Demonstrated

- Data Cleaning and Preparation
- Exploratory Data Analysis
- Excel Data Analysis
- PivotTable and PivotChart Creation
- KPI Development
- Data Visualization
- Dashboard Design
- Business Insight Generation

## Project Outcome

This project demonstrates how Excel can be used to transform social media data into a structured and interactive analytics dashboard. It strengthened my practical skills in **data analysis, visualization, and dashboard development**.
